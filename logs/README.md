# Curated Project Logs

Runtime logger output belongs under ignored `backend/logs/`, not here. Root `logs/` contains only four curated, human-readable Markdown files: this policy, `PROJECT_HISTORY.md`, `TASK-007_COMPLETION.md`, and `TASK-008_START_CHECKPOINT.md`.

Never place passwords, secrets, raw tokens, request payloads, personal acceptance data or raw debug output here. Canonical technical instructions belong in `docs/`; these files only preserve concise milestones.
